Adaptive Spot Bot — Testnet Edition
Windows 多币种测试网桌面版 0.4.0（未签名，客户下载验收仍待完成）

多币种使用：右上角点击“刷新币种”，列表读取测试网实际可交易的 USDT 现货对。
每次仅运行一个交易对；停止机器人并处理完程序持仓及待核对委托后，才可切换。
切换后要重新只读连接并手动开始，不会自动交易。币种可用性会随测试网变化。
旧 BTC 数据仍在原 .paper-data；其他币种在 markets/交易对/.paper-data，各自保留订单、持仓、零头与风险统计。
预算仍为每个当前交易对最多 100 虚拟 USDT；风险记录按交易对计算，不是共享投资组合的风险上限。
软件许可证、测试网 API 与 PEM 共用，无需每个币种重新注册密钥。换 API 后，旧币种记录分别核验后接续。

同一测试网账户更换 API：在密钥配置页填入新 API 及配套 PEM/Secret，点保存。
出现“更换同账户 API”提示后确认，只读核对新旧 API 的账户编号（测试网未返回编号时
核对双方可读取的同一笔私有历史订单）；一致才保留并接续
全部订单、持仓和风险统计，旧记录及加密配置备份在数据目录 account-key-backups。
未核实的旧账户身份、不同账户、待核对委托或运行中的交易锁都会阻止接续。
这不是清空历史功能。保留原 API，先完成只读连接；新 API 的公钥必须与所选 PEM 配套。
重装、续订和更换 API 是独立操作，正常续订不要求更换交易所密钥。

本版已切换到 Cloudflare 授权服务。旧版不会自动换地址；先安全停止并关闭软件，
再运行本版安装器修复/升级。无需更换原币安 API Key、PEM 或订阅许可证。

这是真正连接 Binance Spot Testnet 的自适应虚拟交易机器人，
不是离线 EMA 教学回放工具。没有实盘开关。

一、电脑要求
Windows 10/11，64 位，.NET Framework 4.8。
安装包已内置 Node.js 24.15.0，不用自己安装 Node、npm、Python，
不用运行终端、逐个打开源码文件或编辑 .env。
需要自行取得并有资格使用 Binance Spot Testnet 账户，且本机网络允许访问。
本程序不突破地区限制，也不会自动更改代理或系统电源设置。

二、安装
1. 核对同包 SHA256SUMS.txt 中的校验值和文件来源。
2. 双击 AdaptiveSpotBot-Testnet-Setup.exe，阅读提示后点“Install / 安装”。
   安装只写当前用户目录，不申请管理员权限，不自动开始交易。
3. 安装完成后点击“打开交易工作台”，或从桌面/开始菜单打开 Adaptive Spot Bot Testnet。
   应用默认进入交易总览，不是安装器。尚未连接时显示明确占位，绝不生成假行情。
   重复打开安装器时，可点“修复 / 升级应用”，不再因旧安装目录存在而直接失败。
   升级会保留原桌面数据，把旧应用目录及未知附加文件保存在带时间的 backup 文件夹。
   修复前先安全停止并关闭旧窗口；不要为了升级删除交易锁或持仓记录。
   程序未签名，Windows 可能提示发布者未知。不要关闭杀毒软件或绕过拦截；
   若被安全系统阻止，请停止并交由人工核实来源。它不是 Windows 认证产品。

三、先核验自己的订阅
1. 左侧打开“订阅授权”，输入 Whop 订单/软件许可证界面提供的许可证。
   这不是 Binance API Key。许可证只发送给卖家的固定 HTTPS 授权服务，
   不会向该服务上传交易所密钥、余额、持仓或订单。许可证用本机 DPAPI 加密保存。
2. 点“验证并保存许可证”。有效订阅和测试网只读连接都通过后，仍须手动开始。
   若显示“授权服务未配置”，交易已锁定，不能靠输入任意许可证解锁；
   请联系卖家取得完成正式配置与验收的版本。LOCKED-QA 包只供离线验收，不可出售。
3. 启动前必须联网核验；运行时每 30 秒复查，签名租约最多 120 秒，
   不代表可以断网继续交易 120 秒。断网核验失败、服务不可用、到期或撤权
   会阻止新操作并请求停止；在途请求可能仍完成，不能保证瞬间停止。
4. 取消自动续费可继续用至已付费期限结束，届时停用；平台提前退款/撤权除外。
   到期停用不会平仓或撤单，本机止盈止损等保护也随之停止。
   需要你自行在测试网核对并管理持仓/委托；不要把停用当作清仓。
   记录查看、只读连接账户与安全停止仍保留，不提供长期离线授权。
   续费或网络恢复不会自动重启交易，须重新核验后由你明确启动。

四、配置自己的测试网密钥
1. 在左侧打开“密钥配置”。首次安装没有密钥，不会自动连接账户。
   已保存的密钥重开时会在本机恢复配置，但不会自动联网或启动交易。
2. 如需 Ed25519，点“生成／找回本机 Ed25519 密钥”。
   首次点击会在本机同时生成公钥与私钥，并自动填写 PEM 路径，不需要事先准备私钥。
   已有密钥会找回并复用，不覆盖私钥；续费、取消后重订不会自动更换币安密钥。
   复制下面的 PUBLIC KEY（公钥），自行去 https://testnet.binance.vision/
   登录并选择 Register Public Key 注册公钥，取得 API Key。币安返回的是 API Key，不是私钥。
   只开读取与测试网现货交易所需权限。Whop 的 apik_ 商户密钥只属于卖家服务端，不能填到这里。
   不需要也不提供提现功能；不要把私钥、Secret 发给卖家或客服。
3. 填 Testnet API Key；私钥路径会自动填入。
   如已有 Ed25519 PEM，选 Browse；不会自动复制或加密外部 PEM。
   如测试网账户提供 HMAC，可改用 API Key + HMAC Secret，并清空 PEM 路径。
   HMAC 和 PEM 二选一。不要填实盘 API Key。
4. 点“仅保存到本机”，再点“重新测试连接”；也可点“保存并连接（只读）”。
   保存不会联网。测试连接只读，不做试单、不提交订单。
   canTrade=false 表示当前测试账户没有交易权限，先自行核对权限。
   连接失败、时间错误、HTTP 451 或地区拒绝，不等于策略没触发。

五、开始和查看交易
1. 打开左侧“交易总览”（也是默认首页）。
2. 首次使用请用没有旧程序持仓的新测试账户；或者先完成经审查的人工迁移。
   旧源码版的账户记录不会自动迁入，旧版的锁不能保护新目录。
   停止其他电脑、旧目录、其他副本的同账户机器人，核对账户与持仓。
3. 勾选“仅虚拟资金”和“无其他副本/旧程序持仓”确认。
4. 确认订阅有效。点“开始虚拟交易”，阅读弹窗后确认，并再次在线核验，
   才会启用虚拟资金自动交易；只读连通或 canTrade=true 不等于已有订阅权限。
5. 约每 5 秒判断一次；不是每 5 秒强制成交。
   首页显示价格、虚拟 USDT、程序持仓、进程状态和本机订单；
   图表是最近已收盘的 1 分钟收盘价折线，不是完整 K 线或逐笔实时行情。
   只读监控连接失败与交易进程状态分别显示，不能把“监控断线”当成“机器人已停”。
   使用原来的 adaptive/short 策略：EMA、RSI、ATR、5 分钟环境、动量、
   点差和成本过滤，符合条件时分批买入；本程序持仓预算最多 100 虚拟 USDT。
   止盈、止损、趋势退出和约 3 分钟持仓超时均是本机策略条件，
   不保证成交时间、不保证最大亏损、不保证盈利。
6. 表格显示本桌面版记录的订单，不会冒充账户全部历史成交。
   账户余额/价格是“刷新账户”取得的只读快照；自动刷新约 21 秒。
   未核实的损益显示 unverified，不等于已确认净利润。

六、停止、关闭、重开
“安全停止”会写安全停止请求，等待在途工作处理，不强杀进程。
停止/关闭不卖出持仓、不撤销委托，不是“一键清仓”。
关闭窗口会等待本机控制器/机器人退出；遇到在途请求可能需要等待。
断电、强杀、休眠、断网后，本机退出保护可能无法执行。
程序不会开机自动运行，也不会错误后无限重启或自动重发结果不明的订单。
下次打开会恢复已保存的本机配置并尝试联网核验已保存的订阅许可证，
但不会自动连接测试账户或开始交易，仍需只读测试连接并明确点击开始。
若遗留锁/待核对订单阻止启动，不要删锁、删记录、换目录来强行运行。
先在测试网人工核对在途订单和本程序持仓，再由技术支持审查恢复。

七、本机数据与卸载
应用：%LOCALAPPDATA%\Programs\AdaptiveSpotBotTestnet
密钥配置/交易记录：%LOCALAPPDATA%\AdaptiveSpotBot\Testnet
API Key、HMAC Secret、PEM 路径和订阅许可证用当前 Windows 用户 DPAPI 加密保存。
生成的 PEM 私钥是未额外加密的文件，保存在当前用户专属权限目录。
原来选取的外部 PEM 权限由你自己负责。管理员或以你身份运行的恶意软件仍可能访问。
不上传交易所密钥或交易记录；授权服务会接收订阅许可证与随机会话核验信息。
不收集额外遥测；本地记录也不要公开上传。
卸载前先安全停止并关窗。在 Windows“已安装的应用”中卸载。
卸载只删除安装清单中未被修改的程序文件和本程序快捷方式；
保留密钥、订单、持仓与安全锁。空目录或临时卸载程序可能保留。
升级须先安全停止并关闭旧窗口，然后运行新版安装器修复 / 升级。
不必先卸载 0.1.0 桌面版；旧应用会保留备份，当前用户的桌面版记录继续保留。
不要手工把旧源码包的 .paper-data 或 .env 直接覆盖到桌面版。
