# Adaptive Spot Bot · Live Personal 0.1.0

这是个人自行运行的币安正式现货程序。支持按官方目录选择 USDT 现货交易对、自适应 EMA / RSI / ATR 信号、外置 JSON 规则、真实限价 IOC 委托、手续费与成交账本、客户复盘报告。每个资金账本同一时间管理一个主要交易对，零碎余额继续计入权益。

## 打开与配置

1. 解压对应系统的完整 ZIP。Windows 双击 `Start-Live.cmd`。Mac 打开 `Start-Live.command`。Linux 在目录里运行 `bash Start-Live.sh`。
2. 程序打开本机浏览器控制页。保持启动窗口运行，关闭启动窗口后自动策略也会停止。
3. 在币安官方创建你自己的正式现货 API，配置账户读取和现货交易。程序仅使用现货查询、限价 IOC 委托和本程序委托的撤单接口。
4. HMAC 用户填写 API Key 和 Secret。Ed25519 用户可导入私钥 PEM，也可点「生成实盘注册公钥」，把显示的公钥注册到币安正式 API，再把币安返回的 API Key 填回来。
5. 选择交易对与买入比例。默认每次买入用程序可用 USDT 的 1%，可以改成 2% 或自行选择其他比例。单笔和总投入没有固定美元金额上限。首次核对时会把该账户的可用 USDT 作为本程序资金账本起点，用户应先在账户中自行安排好要使用的资金。
6. 设置至少 12 字符的本机保险箱密码，保存配置。保险箱使用 scrypt 与 AES-256-GCM 加密，密码遗失时需要重新提供 API 凭据。重新启动后先用原密码解锁。
7. 点「只读核对账户与信号」。页面显示正式账户的程序权益、交易规则、费用和判断结果。核对操作本身不创建委托。
8. 亲自输入 `START REAL SPOT TRADING`，再点「启动实盘策略」。启动后每五秒按信号检查，不保证每五秒成交。

## 仓位、费用与每日停买

内置默认 1% 买入，最多三次符合加仓条件的分批。用户可以选择比例，外置 v2 策略的 `sizing.buyPercent` 也可以设置比例。JSON 文件最大 8 KB，旧版 v1 进入和退出规则可直接导入，v1 沿用当前界面的买入比例。

低于币安最小数量或最小订单额时，程序显示阻挡原因。比如资金 100 USDT 的 1% 只有 1 USDT，可能低于交易对最低额，程序会等待。首次进入还检查退出费用和价格回落的余量。

程序权益由本程序可用 USDT 与本程序持仓的卖出估值组成，包含实际费用与预估卖出费用。账户原有的其他币种和手工持仓不自动纳入程序。其他币种支付的费用按核对时的 USDT 价格加 1% 保守余量计入。

每日按北京时间 UTC+8 零点分界。后续日的零点基准由本程序成交账本和零点一分钟开盘价重建。首次建立账本的当日从建账资本开始统计。零点价格取不到时程序暂停，页面显示原因。

当日权益低于参考权益的 80% 时，当天锁定新增买入。即使当日权益回升，锁定仍保留到下一日。已持有的本程序仓位继续按止损、止盈和退出规则管理。20% 是触发阈值，断网、行情跳变和成交延迟可能使实际损失超过阈值。

每天和程序运行期间，尽量通过本程序管理分配给它的 USDT 与持仓。外部手动交易或资金划转造成程序账本和账户余额不足以匹配时，程序暂停以供人工核对。

## 委托结果与暂停

每次委托先在本机保存唯一订单号，再调用正式下单接口。超时和结果不明时停止新委托，保留待核对记录。再次核对时只按原订单号查询，不重复下单。

部分成交的 IOC 委托按币安的最终状态和该订单的完整成交明细入账。手续费、净持仓和现金变动全部核对一致才结束待核对状态。需要撤销尚未终结的本程序委托时，点「核对并撤销遗留的本程序委托」。

「立即停止新委托」停止后续提交，已在交易所成交的交易仍需核对。启动窗口关闭或电脑关机后，本机程序不能继续管理持仓。小于币安最低订单额的零碎余额会保留在账本里，继续计入权益。

## 复盘与客户讨论

点「导出复盘方案」获得 Markdown 报告，内容包括当日损益、交易、费用、停买原因、最新信号和讨论问题。你和客户可以据此讨论新仓位或新规则，确认后再调整界面或导入外置 JSON。

本版提供可复制的复盘材料。接入自动 AI 复盘需要另选模型、API 付费方式及用户授权，当前导出过程只在本机生成报告。

## 当前验证范围

该个人版本必须经过离线模拟交易所回归与对应系统的本地启动检查。真实账户权限、网络、实际成交和资金损失由使用者自行启动后核验。包中的验收记录注明实际完成的测试，不能把离线成交样本描述成真实成交业绩。

客户版还需要独立的实盘商品、对应的订阅权限与交付验收。现有 Whop Testnet 商品说明和许可证只覆盖测试网版本。
