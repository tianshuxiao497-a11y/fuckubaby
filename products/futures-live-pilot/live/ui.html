从配置到多空策略
  1. 填写本人合约 API 或解锁已有本机配置。读取币安现有合约设置，核对当前权益。
  2. 选择永续合约、初始保证金比例、全仓或逐仓、杠杆与交易方向，保存本机配置。
  3. 如所选模式或杠杆与币安不同，空仓后输入确认文字，再应用所选设置。
  4. 只读核对账户和信号，处理已有或未知委托。已有手动仓位不会被接管。
  5. 沿用内置双向指标，或导入专用于合约的 JSON。现货 JSON 不能直接当作空头规则。
  6. 亲自输入 START REAL FUTURES TRADING 并启动。约每五秒检查一次，出现有效条件才提交委托。

费用与日内风险
按真实成交、佣金和资金费计算权益。滑点已反映在成交价中，不再次扣作一笔额外费用。币本位担保币按实际现货价格折合 USDT，包含币价本身变化。
每日以 UTC+8 零点为分界，首日从本程序建账时刻起算。回撤超过 20% 后锁定当天新增多空仓；已有程序仓位仍可减仓和平仓。此阈值不能保证实际亏损不超过 20%。
保护、停止与异常
开仓与提交交易所止损不是原子操作。若止损尚未确认、订单结果不明或账户发生外部资金变动，会停止新委托并保留原记录。请先核对；紧急时可到币安手动处理。
已被交易所接受的条件止损可在程序关闭后继续存在，但触发、成交与成交价均不保证。止盈、追踪退出等本机规则在关机后停止。平仓后等待至少一分钟再开新仓，每小时最多六次新开仓。
不要在同一对合约钱包中并行手动交易或运行其他机器人。本版要求标准合约账户、可读取的两个合约钱包及 U 本位单资产保证金模式；不支持统一组合保证金账户。
