# Adaptive Futures Bot · 合约实盘自用版 0.1.0

这是卖家本人先行验收的真实资金合约程序。不是币安测试网，不是原测试网客户安装包。当前没有接入客户订阅授权，请勿把本包替换到已有 Whop 测试网商品中。自动测试使用虚构账户；真实账户权限、条件单能力和实际成交仍需本人验收。

## 包含什么

- U 本位 USDT／USDC 永续与币本位反向永续；按币安当前目录筛选，不支持交割合约。
- 多仓、空仓、只开多、只开空；内置 EMA／RSI／ATR 规则，或导入专门的双向 JSON 规则。
- 全仓或逐仓、读取并选择账户允许的杠杆档位；不会自动设置为最大杠杆。
- 每次开仓初始保证金为两个合约钱包总权益折合 USDT 的 1%–2%，默认 1%。杠杆会扩大合约名义金额。
- UTC+8 日内权益回撤超过 20% 后，锁定当天新增多空仓，允许已有程序仓位退出。包括实际佣金、资金费、未实现盈亏和担保币价格变化。
- 本机加密 API 配置、账户核对、交易所止损、原订单核对、CSV 和本地复盘报告。

本版一次只管理一个永续合约、一笔程序持仓。两个合约钱包都必须可读取；U 本位须使用单资产保证金模式。不支持统一组合保证金。不会接管手动持仓、其他机器人订单或旧现货账本。不要在这两个合约钱包中同时运行其他机器人或手动交易。

## 四个平台安装

- Windows x64：解压 ZIP，运行其中的安装 EXE；保留已有应用数据，启动 Adaptive Futures Bot。
- Ubuntu／Debian x64：先完整解压 ZIP，再用系统软件安装器安装其中的 DEB。依赖缺失时，可在该目录终端使用 `sudo apt install ./AdaptiveFuturesBot-0.1.0-linux-amd64.deb`。安装后在应用列表找 Adaptive Futures Bot。
- Apple Silicon Mac：使用 arm64 ZIP；Intel Mac 使用 x64 ZIP。解压后把 Adaptive Futures Bot.app 放入 Applications。
- macOS 尚未经过 Apple 公证，Windows 未签名。若系统阻止，先确认来源和包内校验记录，再使用系统提供的“仍要打开”或对应允许操作；不要全局关闭系统安全保护。

Linux 在 Windows 上下载文件不会切换操作系统；需先进入 Linux 再安装。四种包都是桌面程序，不是手机应用。

## 首次配置

1. 打开“账户与合约”。设置一个至少 12 字符的本机保险箱密码，并再次输入。记住密码；本程序没有云端找回服务。
2. 使用本人币安正式合约账户的 API，开启所需的账户读取及合约交易权限。不需要提现权限。填写 API Key，并二选一填写 HMAC Secret 或 RSA PEM。
3. 若使用 RSA，可以在软件内生成注册公钥，再在币安注册这个公钥，取回对应 API Key。币安返回的 API Key 不是私钥。私钥由本机生成并加密保存；生成或找回公钥使用同一个密码。不要把现货 Ed25519 PEM 当作本版 RSA PEM。
4. 选择 U 本位或币本位及永续合约，点击“读取币安现有设置（只读）”。这一步不会改变保证金模式、杠杆或创建订单。
5. 核对读取的模式、杠杆、总权益和已有仓位。选择保证金占比 1%–2% 和方向，首次保存加密配置。解锁后的自动连接仅做只读检查，不会自动开始交易。
6. 若本机选择与币安不同，先空仓、停止且核清原订单，输入 `APPLY FUTURES SETTINGS`，再点击应用。只改所选合约的模式和杠杆，不改变账户单双向持仓模式。逐仓须先在币安关闭自动追加保证金。
7. 回到总览点击“只读核对”。确认账户、费用、保证金与杠杆、信号、计划名义金额和保护状态。额度不够交易所最小量时会等待，不会擅自放大仓位。
8. 本人输入 `START REAL FUTURES TRADING` 后点击启动。约每五秒检查一次，满足规则才下单。开仓采用限价 IOC，可能不成交或部分成交；按真实成交量记账。平仓后至少等待一分钟再开仓，每小时最多六次新增仓位。

重新打开程序需要解锁本机保险箱。API Key、RSA 私钥或 HMAC Secret 不会上传到 Whop／Cloudflare 授权服务。不要在聊天、截图、策略 JSON 或安装包中附带密钥。

## 保证金、费用与退出

例如总合约权益 1000 USDT，选择 2%，开仓初始保证金预算为 20 USDT；10 倍杠杆对应约 200 USDT 名义金额，实际数量还受价格和最小交易步长限制。这个 20 USDT 不是全仓的最大损失承诺。全仓会涉及其他可用担保资金；逐仓追加保证金也会扩大风险。

交易佣金随开／平仓实际成交记账。滑点体现在成交价中，不额外重复扣一笔“滑点费用”。持仓跨资金费结算会支付或收取资金费。实际强平、清算费及无法解释的资金变化需要在币安核对；本程序不会把这些异常悄悄归零后自动恢复。

每日以 UTC+8 零点为分界。首次使用当天以建账时权益起算，之后用真实账本和零点历史价格还原基准。当天回撤超过 20% 后，即使权益回升也不会重新开仓。第二天有可靠的新基准后才能解除当天锁定；异常或断线后仍需本人启动。20% 是停止新增仓位的触发阈值，不保证最终亏损封顶 20%。

开仓与提交交易所条件止损是两个独立请求，存在短暂无保护窗口。程序先核对条件单查询能力，成交后提交按标记价格触发的 STOP_MARKET；若失败、超时或止损距离已经越过当前价格／强平价，会停止并保留记录。需要立即查看币安账户，必要时本人平仓。

点击“停止自动策略”会停止后续自动执行，已成交仓位不会撤回，已确认的交易所止损保留。点击“市价平本程序持仓”需再次输入真实交易确认文字，且只处理已核对的程序仓位。市价成交和止损触发／成交价均不保证。关机后，本机止盈、追踪退出和复盘计算停止；交易所已接受的止损由交易所处理。

当仓位部分退出、保护数量不再匹配、账户变化或订单结果不明确时，不再自动开新仓。先“核对原订单”，不要反复点击启动或删除账本。紧急时到币安核对并处理；手动处理可能使本机账本需要人工复核。

## 外置 JSON 与复盘

导入只接受数据规则，不能执行任意代码。示例见 `example-futures-strategy.json`，分别写明 long／short 的 entry／exit 及止损、止盈、追踪距离。规则中的百分比是标的价格变化口径，不是保证金收益率。JSON 不会悄悄修改杠杆、保证金比例或每日停开规则。需停止、空仓且核清委托后导入或恢复内置规则，并输入本机保险箱密码保存。

“导出复盘”生成本地 Markdown：权益、当天基准、模式杠杆、实际委托及资金费，并列出复核问题。它不会自动向客户发送消息或调用付费 AI，也不保证策略盈利。可以用报告讨论下一轮规则后再修改 JSON。

## 本机文件与备份

- Windows：`%LOCALAPPDATA%/AdaptiveSpotBot/FuturesPersonal`
- Linux：`$XDG_DATA_HOME/AdaptiveSpotBot/FuturesPersonal`，默认 `~/.local/share/AdaptiveSpotBot/FuturesPersonal`
- macOS：`~/Library/Application Support/AdaptiveSpotBot/FuturesPersonal`

加密文件为 futures-vault.json，账本为 futures-ledger.json。只在程序完全退出、原订单已核对后备份整个目录。不要删除交易记录解决错误，不要同时在两台设备运行同一个账户。保存新配置会保留旧加密配置备份。

## 验收范围

本包附带原生离线启动验收和文件校验记录，使用虚构账户验证多空、费用、保护触发、断线和日内基准。尚未使用真实账户下单，也不是可直接对外承诺完成实盘验收的客户版。首次自行验收请先只读核对，再亲自决定资金与杠杆。已有测试网客户订阅与下载不受本包影响。
