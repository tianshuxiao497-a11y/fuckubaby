# 统一实盘工作台 0.3.0：当前授权与实现记录

用户已明确启动三项修改：现货＋合约同一应用入口；独立多空策略及手动等量锁仓；逐仓保证金状态显示及手动追加。四个平台同版本，中英文指南。继续卖家自用验收，不发布或替换 Whop 测试网客户商品。

用户异步确认（2026-11-19）：
- 双向：两种都要——策略独立管理多空，也提供手动等量锁仓按钮。
- 追加最初确认显示真实状态＋手动追加；用户随后明确增加：自动追加只由客户自设外置 JSON，不提供内置自动追加规则。保留已有内置交易策略。

风险口径沿用：每次新开仓初始保证金占总合约权益 1%–2%；日内 UTC+8 权益回撤超过 20% 停止新增多空，保留减仓平仓。锁仓的新反向开仓也遵守预算、资金和停开限制；不自动提高杠杆或扩大预算来凑等量。不向币安下真实单，不通过工具读取真实交易密钥。

设计：
1. 统一桌面应用内提供现货、合约两个切换页，保留原配置目录与各自账本。切换页面不会暗中重启交易；总停止按钮停止两套自动策略。仅允许本机随机端口、已确认父页面嵌入，默认独立页面仍禁止嵌入。
2. 合约账本升级为按 LONG/SHORT 分离的 positions/protections，兼容迁移旧版单仓账本并保留记录。一个选定永续合约，至多一多一空；真实交易所双向持仓模式需要单独确认，且 UM/CM 均空仓、无委托才能切换。
3. 多空共用账户日内权益、佣金、资金费和担保币估值；保护单、平仓、订单恢复分别关联方向。未知请求只核对、不重发。
4. 手动锁仓时暂停策略，按已有程序仓位的净数量建立反向仓；部分成交如实显示，不自动补单。手动锁仓状态保持暂停，须用户明确解除后才可再次启动自动策略。保护单仍有效，不保证永久等量或收益冻结。
5. 手动追加仅使用官方 POST /fapi/v1/positionMargin 或 /dapi/v1/positionMargin，type=1，方向明确、金额按原生保证金币种输入。先记录意图，再请求；超时不重复追加，查询官方 margin change history 核验。追加在钱包内重新分配，不作为额外充值计入权益。
6. 显示币安实际 auto-add 状态：开启／关闭／未返回。当前公开普通合约资料没有找到可核实的自动追加开关写接口；不能伪造可用开关。普通逐仓且实际开关关闭时不再提示用户额外关闭。
7. 本机 JSON 自动追加与币安原生自动追加区分。仅外置 JSON 指定 enabled、策略 ID、market/symbol/asset、LONG/SHORT 方向、强平距离触发、单次原生币金额、两腿合计自动追加累计预算、次数与冷却间隔。未导入或未在界面单独确认启用时默认关闭；重启需再次确认；全局停止同时停交易和自动追加。无可核对强平价、未知请求、保护未确认、日内 20% 锁定时不自动追加。相同策略 ID 的累计已用预算持久化，不能通过重启或重复导入重置。只有匹配原生资产的官方 margin history 确认后才计入预算；超时不能重复追加。不给可直接花钱的内置模板参数，提供默认禁用、零金额的 JSON 格式样例及说明。
